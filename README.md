One sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer, for make.fun's "Loading Screen Gold: A Tip in 200 Characters" bounty. The tip is: "Tip: while this loads, your agent is waiting on the one dependency it cannot install: your approval." The joke lands on the approval loop every agent builder knows: the agent has done the work and the only thing left is the human saying yes.

## Run it

```sh
python3 main.py
```

The program writes the tip to /output/entry.txt.
